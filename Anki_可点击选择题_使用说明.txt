Anki 可点击选择题模板使用说明

你现在拿到的是“字段化 CSV + 模板代码”版本。
因为 Anki 不能通过 CSV 自动创建带 JS 的交互模板，所以需要先在 Anki 里手动新建一个笔记类型，再导入这个 CSV。

一、你会用到的文件
1. 艺术概论_Anki_可点击选择题版_字段化.csv
2. Anki_可点击选择题_正面模板.txt
3. Anki_可点击选择题_背面模板.txt
4. Anki_可点击选择题_样式.txt

二、在 Anki 里创建新笔记类型
1. 打开 Anki
2. 工具 → 管理笔记类型
3. 选中“问答题”或“Basic”
4. 点击“复制”
5. 名称改成：可点击选择题
6. 打开“字段”，按下面顺序创建字段：

Stem
A
B
C
D
E
CorrectLetters
Answer
Type
Tags

如果已有多余字段，可以保留，不影响使用。

三、粘贴模板
1. 在“管理笔记类型”中选中“可点击选择题”
2. 点击“卡片”
3. 将“正面模板”全部替换为：
   Anki_可点击选择题_正面模板.txt 里的内容
4. 将“背面模板”全部替换为：
   Anki_可点击选择题_背面模板.txt 里的内容
5. 将“样式”全部替换为：
   Anki_可点击选择题_样式.txt 里的内容

四、导入 CSV
1. 文件 → 导入
2. 选择：艺术概论_Anki_可点击选择题版_字段化.csv
3. 笔记模板选：可点击选择题
4. 字段分隔符选：逗号
5. 字段映射如下：

列1  -> Stem
列2  -> A
列3  -> B
列4  -> C
列5  -> D
列6  -> E
列7  -> CorrectLetters
列8  -> Answer
列9  -> Type
列10 -> Tags

注意：
- “允许在字段中使用 HTML”可以开着
- 标签如果你想让 Anki 真正识别为标签，建议导入后在字段映射里把 Tags 映射到“标签”
  如果你的版本不支持直接映射到标签，也可以先导入成普通字段，不影响刷题

五、使用效果
1. 选择题：
   - 正面会显示可点击选项
   - 单选题点击后立即判定
   - 多选题可多选，点“提交答案”判定
2. 非选择题：
   - 正面只显示题目
   - 仍然使用“显示答案”查看背面

六、关于这份题库
- 原始 CSV 中真正带 A/B/C/D/E 选项的题目数量有限
- 其余填空、简答、论述题会自动按普通问答卡显示
- 所以这是“混合题型可用”的模板，不会把非选择题弄坏
